이미지 형식이 너무 많아서 무엇을 써야 할지 모르겠다면 아래 표와 질문을 따라가 보세요. 각 형식의 역사와 상세한 특징은 [형식 설명](/formats/) 페이지에 있습니다.

## 질문 세 개로 고르기

1. **투명 배경이 필요한가요?** 필요하면 JPG와 BMP는 후보에서 빠집니다. PNG, WebP, GIF, AVIF, SVG 중에서 고릅니다.
2. **사진인가요, 그래픽인가요?** 사진은 JPG나 WebP, AVIF가 작습니다. 로고·글자·스크린샷은 PNG가 선명합니다.
3. **어디에 쓰나요?** 받는 쪽이 어떤 형식을 열 수 있는지가 마지막 기준입니다. 확실하지 않으면 JPG나 PNG가 안전합니다.

## 용도별 추천

| 용도 | 추천 | 이유 |
| --- | --- | --- |
| 일반 사진 공유, 이메일 | JPG | 어디서나 열리고 용량이 작음 |
| 웹사이트에 올리는 사진 | WebP (대체로 JPG와 함께) | 같은 화질에서 더 작음 |
| 로고, 아이콘, UI 이미지 | PNG 또는 SVG | 선명하고 투명 지원. SVG는 확대해도 깨지지 않음 |
| 스크린샷, 글자가 많은 이미지 | PNG | JPG는 글자 주변이 번짐 |
| 편집용 원본 보관 | PNG (사진은 TIFF도) | 무손실이라 재저장해도 열화 없음 |
| 파비콘, 윈도우 아이콘 | ICO (또는 PNG, SVG) | [파비콘 가이드](/guides/make-favicon/) 참고 |
| 짧은 움직이는 이미지 | GIF 또는 WebP | GIF는 어디서나 재생, WebP는 더 작음 |
| 아이폰 사진 공유 | JPG | HEIC는 윈도우·웹에서 열리지 않는 경우가 많음 |

## 용량은 얼마나 다를까

같은 사진(1280×854)을 여러 형식으로 저장한 결과입니다. 품질을 지정할 수 있는 형식은 90입니다.

| 형식 | 용량 |
| --- | --- |
| WebP | 370KB |
| JPG | 417KB |
| GIF | 656KB |
| PNG | 2.2MB |
| BMP | 3.1MB |

스크린샷처럼 평면 색과 글자가 많은 이미지(1280×720)로 바꿔 측정하면 순서가 달라집니다.

| 형식 | 용량 |
| --- | --- |
| WebP (품질 90) | 44KB |
| JPG (품질 90) | 105KB |
| PNG | 108KB |

이미지 종류에 따라 유리한 형식이 달라지므로, 중요한 이미지는 후보 형식으로 한 번씩 변환해 결과 화면의 용량을 비교해 보는 것이 가장 정확합니다. 자세한 비교는 [PNG vs JPG](/guides/png-vs-jpg/), [WebP vs JPG](/guides/webp-vs-jpg/)에 있습니다.

## 피하는 편이 좋은 경우

- **BMP**: 압축이 없어 용량이 큽니다. 구형 장비가 요구하는 경우가 아니면 쓸 이유가 거의 없습니다.
- **GIF로 사진 저장**: 256색 제한으로 사진이 거칠어지고 용량도 큽니다.
- **JPG를 PNG로 바꿔 화질을 높이려는 시도**: 이미 사라진 정보는 돌아오지 않습니다.
- **JPG를 반복 재저장**: 저장할 때마다 열화가 쌓입니다. 원본에서 한 번만 변환하세요.
