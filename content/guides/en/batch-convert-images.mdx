On a site that converts one image at a time, a folder of thirty images means repeating the same steps thirty times. This site was built from the start to handle many files in one go.

## The basic flow

1. **Select all the images in a folder and drag them in together.** You can also click to choose several, or paste an image copied to the clipboard with Ctrl+V.
2. Choose the output format.
3. Set options such as quality, size and background color. **The same settings apply to every file.**
4. Press Convert, and when it finishes press **Download all as ZIP**.

## Mixed formats are fine

A folder with PNG, JPG, WebP, HEIC, TIFF and SVG files can go in as it is. Each file's format is detected separately. If a file has the wrong extension, it is processed by its real format and the list tells you which file it was. An unsupported file is marked as an error in the list, and the rest convert normally.

## Matching sizes at the same time

To bring images of mismatched sizes to one spec, set Size to **Set exact size (width × height)**. For images with a different ratio, you can stretch or squash them, center them and fill the leftover area, or fill the frame and crop. [Unify Image Sizes for Games](/guides/unify-image-size-for-games/) covers this in detail.

## What to know about the ZIP

- Result files **keep their original names**, and only the extension changes (for example `photo.heic` → `photo.jpg`).
- If files from different folders share a name, numbers are added inside the ZIP, as in `photo (2).jpg`.
- Each file shows its size before and after and the percentage change, so you can see where the savings are largest.
- You can also download files one at a time with each file's **Download** button.

## Batch speed, measured

For the test, 100 photos were created (27.9MB in total, 286KB each on average, about 950×1270) and converted together from JPG to WebP at quality 80. The site was served locally and timed in Chromium on the PC used to write this guide, a development desktop.

| Files | Time to convert | Time to build the ZIP | ZIP size |
| --- | --- | --- | --- |
| 10 | 2.8 s | 0.1 s | 1.3MB |
| 50 | 4.4 s | 1.9 s | 6.6MB |
| 100 | 6.4 s | 1.8 s | 13.1MB |

All 100 files converted, the downloaded ZIP held every one of them, and the archive passed an integrity check. The 27.9MB shrank to 13.1MB. The time for 10 files includes first-run setup. Below is the result screen for the 10-file run.

![The result screen after converting 10 photos to WebP. Each file shows its size before and after and the percentage change, with a Download all as ZIP button at the top](/images/guides/batch-result-10.png)

Speed varies a lot with the PC and browser. Batches larger than 100 were not measured.

## Limits and tips

- Each file can be up to **50MB**. There is no limit on the number of files, but browser memory is finite, so a very large batch can run slower than the measurements above. For sizes that weren't measured (several hundred files or more), splitting the batch is safer.
- Files are processed a few at a time in parallel. Conversion runs on separate worker threads, so the page doesn't freeze while it works.
- **If HEIC files are in the batch**, the first one takes a few extra seconds while the decoder downloads. After that they are processed quickly.
- Large TIFFs and very large images can fail for lack of memory. A failed file is flagged in the list and the others are unaffected.
- Animated GIF and WebP files convert only their first frame.

## If you repeat the same job

The format, quality and size settings you used last are remembered in this browser, so the next visit starts from the same settings. They are stored only on this device. To restore the defaults, press "Reset settings" above the options.
