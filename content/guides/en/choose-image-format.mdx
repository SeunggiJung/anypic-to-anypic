If you aren't sure which format to save an image in, work through the questions and table below. The history and details of each format are on the [Formats](/formats/) pages.

## Three questions

1. **Do you need a transparent background?** If so, JPG and BMP are out. Choose among PNG, WebP, GIF, AVIF and SVG.
2. **Is it a photo or graphics?** For photos, JPG, WebP and AVIF come out smaller. For logos, text and screenshots, PNG stays sharper.
3. **Where will it be used?** What the recipient can open is the final test. When you aren't sure, JPG or PNG is the safe choice.

## Recommendations by use

| Use | Recommended | Why |
| --- | --- | --- |
| Sharing ordinary photos, email | JPG | Opens everywhere and is small |
| Photos on a website | WebP (usually with a JPG fallback) | Smaller at the same quality |
| Logos, icons, UI images | PNG or SVG | Sharp and supports transparency. SVG doesn't break when enlarged |
| Screenshots, text-heavy images | PNG | JPG blurs around text |
| Keeping editing originals | PNG (TIFF for photos too) | Lossless, so re-saving doesn't degrade |
| Favicons, Windows icons | ICO (or PNG, SVG) | See the [favicon guide](/guides/make-favicon/) |
| Short moving images | GIF or WebP | GIF plays everywhere; WebP is smaller |
| Sharing iPhone photos | JPG | HEIC often won't open on Windows or the web |

## How different is the file size?

One photo taken for this guide (chicken dish, 960×1280) was saved in several formats with this site's converter. Formats with a quality setting were set to 90.

| Format | File size |
| --- | --- |
| WebP | 300KB |
| JPG | 343KB |
| GIF | 722KB |
| PNG | 2.6MB |
| BMP | 3.5MB |

An image with flat colors and a lot of text ranks differently. The same test on a settings screen drawn for this guide (1280×720) gave this.

| Format | File size |
| --- | --- |
| WebP (quality 90) | 24.7KB |
| GIF | 30.3KB |
| JPG (quality 90) | 50.6KB |
| PNG | 88.0KB |
| BMP | 2.6MB |

GIF came out smaller than JPG here, but it is limited to 256 colors and doesn't suit images with many. Both tables show a single image each, one photo and one drawing.

Which format wins depends on the kind of image. For anything important, the most reliable check is to convert it to each candidate and compare the sizes on the result screen. For closer comparisons, see [PNG vs JPG](/guides/png-vs-jpg/) and [WebP vs JPG](/guides/webp-vs-jpg/).

## What to avoid

- **BMP**: It has no compression, so files are large. Unless old equipment requires it, there is almost no reason to use it.
- **Saving photos as GIF**: The 256-color limit makes photos coarse, and the files are large too.
- **Converting JPG to PNG to improve quality**: Information that is already lost doesn't come back.
- **Re-saving a JPG repeatedly**: Each save adds more degradation. Convert from the original, once.

## If you're still not sure

If you don't know what the recipient can open and you don't need transparency, choose **JPG**. If you need transparency, choose **PNG**. Convert on this site and check the size of the result. If you don't like it, you can convert again to another format right away.

Turning a PNG or similar image into an SVG is more than a format change. The image is redrawn as shapes, which is an estimate, so it suits only logos and icons. Details are in [Converting PNG to SVG: What Works and What Doesn't](/guides/png-to-svg-caveats/).
